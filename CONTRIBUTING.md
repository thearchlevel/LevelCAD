# Contributing

Thanks for your interest in LevelCAD.

1. Open an issue describing the proposed change; discuss architectural features before large PRs.
2. Use C++20, maintain Qt independence for engine modules, and keep changes scoped.
3. Add/update automated tests for changes to engine behavior and file formats.
4. Run `cmake --build` and `ctest --output-on-failure` before opening a PR.
5. Document important design decisions and breaking file-format changes.
6. Contributions are submitted under the repository's GPL-3.0-or-later license.

See `docs/ARCHITECTURE.md` for technical direction.
