# Roadmap (proposed, not commitments)

- **0.1 Foundation**: portable Qt-free core, Qt desktop shell, grid, placement, wiring, basic JSON and tests. (initial skeleton)
- **0.2 Schematic basics**: symbol geometry and pin definitions, electrical connectivity graph, proper snapping, undo/redo, properties, selection and deletion.
- **0.3 Production-grade schematics**: library format, hierarchical sheets, annotation, ERC, netlist and thorough regression suites.
- **0.4 PCB alpha**: footprints, net assignment, board outline, layers, manual track editing, DRC foundation.
- **0.5 Manufacturing pipeline**: Gerber, Excellon, BOM and fabrication validation with reference fixtures.
- **Later**: SPICE, 3D, interactive router, plugins, API stabilization, internationalization.

No version implies a release date or manufacturing readiness.
